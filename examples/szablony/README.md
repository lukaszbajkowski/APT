# Przykładowe szablony

- `medicover_deklaracja.docx` – deklaracja przystąpienia do grupowego ubezpieczenia Medicover jako szablon
  aplikacji (znaczniki `{{ … }}`). Wgraj w **Szablony dokumentów → Dodaj szablon**.
  Dane z kartoteki: nazwisko i imię, PESEL, data urodzenia, obywatelstwo, płeć.
  Pola formularza: rodzaj deklaracji, program, wariant, numer karty, adresy, telefony, e-mail.
  Członków rodziny wpisuje się ręcznie na wydruku.
- `medicover_deklaracja_pusta.docx` – ten sam formularz bez znaczników, do wypełnienia ręcznie.
